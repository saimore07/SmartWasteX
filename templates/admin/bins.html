SmartWasteX IoT Ingestion Gateway Specification

Physical IoT microcontrollers (ESP32, Raspberry Pi, Arduino, LoRaWAN gateways) stream real-world sensor telemetry into the SmartWasteX platform via authenticated HTTP/HTTPS JSON POST requests.

Endpoint Details
Method & URL:
POST/api/iot/bin-update (or /api/iot/telemetry)
Authentication:
Header X-API-Key: {{ iot_api_key }} or Bearer Token
Content-Type:
application/json
JSON Telemetry Payload Schema
{
  "bin_id": "BIN-01",
  "fill_percentage": 85.0,
  "weight": 12.5,
  "temperature": 29.4,
  "battery_level": 90.0
}
Example cURL Transmission
curl -X POST http://127.0.0.1:5000/api/iot/bin-update \
  -H "Content-Type: application/json" \
  -H "X-API-Key: {{ iot_api_key }}" \
  -d '{"bin_id": "BIN-01", "fill_percentage": 85.0, "weight": 12.5, "temperature": 29.4, "battery_level": 90.0}'
